# Голосовой переводчик

Статическое веб-приложение/PWA для голосового ввода на русском, перевода на несколько языков и озвучки перевода системным голосом браузера.

## Возможности

- голосовой ввод на русском через Web Speech API;
- ручной ввод текста как запасной вариант;
- перевод на немецкий, английский и другие европейские языки;
- варианты локали для Германии/Австрии/Швейцарии, Великобритании/США, Испании/Мексики, Португалии/Бразилии;
- озвучка через Speech Synthesis API;
- установка как ярлык/PWA;
- основной перевод через Google Translate web endpoint с резервным MyMemory.

## Запуск через GitHub Pages

Если GitHub Pages для репозитория уже включён из ветки `main`, страница будет доступна по адресу:

`https://marsely-gh.github.io/my-first-project/voice-translator/`

Если Pages ещё не включён: GitHub → репозиторий `my-first-project` → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

После публикации откройте ссылку в Chrome или Яндекс Браузере и разрешите доступ к микрофону.
